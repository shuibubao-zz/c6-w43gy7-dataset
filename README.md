## 运行方式

1. 打开 `卢怡然_C6A_dashboard/index.html`（或仓库 Pages 地址下的同名目录）。
2. 数据重算：`python 卢怡然_C6A_data/scan_submissions.py`，产物写入同目录。
3. 无第三方依赖，Python 3 标准库即可。

## 数据口径

单一配置为唯一口径；20 名学生 × 11 个挑战 = 220 条记录。除本人记录来自真实平台进度外，其余为确定性合成样本，已在方案设计与 AI 日志中明确声明。
